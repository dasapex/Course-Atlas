# Course-Atlas
A tool to track and summarize the progress of courses and units taken within a specific publicly-accessible program curriculum.

[![Launch Course Atlas](https://img.shields.io/badge/Launch-Course%20Atlas-1F7A4D?style=for-the-badge&logo=githubpages&logoColor=white)](https://dasapex.github.io/Course-Atlas/)

[![Deployment Status](https://img.shields.io/endpoint?url=https%3A%2F%2Fraw.githubusercontent.com%2Fdasapex%2FCourse-Atlas%2Fdeployment-status%2Fdeployment-status.json&style=for-the-badge)](https://github.com/dasapex/Course-Atlas/actions/workflows/hugo.yml)

No installation is required. Course Atlas runs directly in your browser.
