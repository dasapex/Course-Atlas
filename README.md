# Course Atlas
Course Atlas is a free, open-source curriculum tracking web app designed to help Civil Engineering students visualize and manage their academic progress. It transforms FEU Tech and TIP curriculum data into interactive, zoomable course maps with prerequisite and co-requisite connections, live completion tracking, remaining-unit summaries, course search, prerequisite-lineage filtering, mobile-friendly navigation, and light and dark themes. Progress is stored locally in the user’s browser, requiring no account, installation, or external database.

[![Launch Course Atlas](https://img.shields.io/badge/Launch-Course%20Atlas-1F7A4D?style=for-the-badge&logo=githubpages&logoColor=white)](https://dasapex.github.io/Course-Atlas/index.html)

No installation is required. Course Atlas runs directly in your browser.
