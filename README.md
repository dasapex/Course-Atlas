# Course-Atlas
A tool to track and summarize the progress of courses and units taken within a specific publicly-accessible program curriculum.

[![Download Offline Version](https://img.shields.io/badge/Download-Offline%20Version-FFD24D?style=for-the-badge&logo=html5&logoColor=0C1813)](https://dasapex.github.io/Course-Atlas/Course-Atlas.html)

No installation is required. Course Atlas runs directly in your browser.
